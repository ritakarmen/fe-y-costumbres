# Fe y Raíces

Revista web en español sobre fe, espiritualidad, noticias religiosas, costumbres y celebraciones. Construida con Astro y preparada para desplegarse en GitHub Pages.

## Ejecutar localmente

```sh
npm install
npm run dev
```

Para generar el sitio estático:

```sh
npm run build
```

## Despliegue

El workflow de GitHub Actions construye y publica el sitio cuando hay cambios en `main`. La URL está preparada para `https://ritakarmen.github.io/fe-y-costumbres/`.

## Consultas y comentarios

Los formularios abren el cliente de correo con el mensaje dirigido a `vidasanacelestial@gmail.com`. La persona decide cuándo enviarlo. Los comentarios llegan para revisión y no se publican automáticamente.

## Actualidad

Las noticias iniciales son una selección editorial con enlaces a sus fuentes originales. No se actualizan automáticamente; hay que renovar la selección al editar el sitio.
